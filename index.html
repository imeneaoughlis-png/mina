Création, Manipulation, Nettoyage et Requêtes Avancées

1. Guide Complet des Commandes (Le "Cheat Sheet")

DDL : Création & Structure
  • CREATE SCHEMA nom; : Organiser tes tables.
  • CREATE TABLE (...) : Définir colonnes et types.
  • SERIAL PRIMARY KEY : Auto-incrément automatique.
  • REFERENCES table(col) : Créer une Clé Étrangère.
  • ALTER TABLE ... ADD/DROP/RENAME : Modifier la structure.
DML : Manipulation des Données
  • INSERT INTO ... VALUES : Ajouter des lignes.
  • UPDATE ... SET ... WHERE : Modifier (Ne pas oublier le WHERE !).
  • DELETE FROM ... WHERE : Supprimer des lignes spécifiques.
  • TRUNCATE : Vider une table proprement.
DQL : Sélection & Affichage
  • SELECT DISTINCT : Éviter les doublons.
  • ORDER BY ... ASC/DESC : Trier les résultats.
  • LIMIT n : Afficher seulement les n premières lignes.
  • LIKE '%txt%' : Recherche textuelle partielle.
Fonctions & Nettoyage (TP3)
  • UPPER() / LOWER() : Harmoniser la casse.
  • TRIM() : Enlever les espaces inutiles.
  • CAST(col AS type) : Convertir (ex: Text vers Decimal).
  • COALESCE(col, 'Remplaçant') : Gérer les valeurs NULL.

2. Examen Blanc : Étude de Cas "Gestion d'une Librairie"

Mélange de tes TP1, TP2 et TP3. Réalise ces 12 étapes dans l'ordre :

Q1. Crée un schéma bibliotheque.
Q2. Crée une table auteurs (id SERIAL, nom, pays) et une table livres (id SERIAL, titre, prix_ht, id_auteur).
Q3. Ajoute une contrainte de clé étrangère entre livres et auteurs.
Q4. Ajoute une colonne stock de type INTEGER à la table livres.
Q5. Insère 3 auteurs et 5 livres (certains avec des prix > 5000 et d'autres < 1000).
Q6. (TP3) Un employé a saisi ' France ' et 'france'. Fais un UPDATE pour que tous les pays soient en majuscules et sans espaces.
Q7. Affiche tous les livres dont le titre commence par la lettre 'L'.
Q8. Affiche le titre du livre et le nom de son auteur (JOINTURE).
Q9. Calcule la valeur totale du stock (Prix * Stock) pour chaque livre.
Q10. Quel est le prix moyen des livres par auteur ?
Q11. Augmente le prix de tous les livres de l'auteur ID n°1 de 15%.
Q12. Supprime tous les livres dont le stock est égal à 0.

✅ Correction Détaillée

-- Q1 & Q2 : Structure
CREATE SCHEMA bibliotheque;

CREATE TABLE bibliotheque.auteurs (
    id_auteur SERIAL PRIMARY KEY,
    nom VARCHAR(100) NOT NULL,
    pays VARCHAR(50)
);

CREATE TABLE bibliotheque.livres (
    id_livre SERIAL PRIMARY KEY,
    titre VARCHAR(200),
    prix_ht DECIMAL(10,2),
    id_auteur INT
);

-- Q3 & Q4 : Modifications
ALTER TABLE bibliotheque.livres 
ADD CONSTRAINT fk_auteur FOREIGN KEY (id_auteur) 
REFERENCES bibliotheque.auteurs(id_auteur);

ALTER TABLE bibliotheque.livres ADD COLUMN stock INT DEFAULT 0;

-- Q5 : Insertion
INSERT INTO bibliotheque.auteurs (nom, pays) VALUES ('Victor Hugo', 'France'), ('Kateb Yacine', 'Algerie');
INSERT INTO bibliotheque.livres (titre, prix_ht, id_auteur, stock) VALUES 
('Les Misérables', 2500, 1, 10),
('Nedjma', 1800, 2, 5),
('L''Homme qui rit', 3000, 1, 0);

-- Q6 : Nettoyage (Style TP3)
UPDATE bibliotheque.auteurs 
SET pays = UPPER(TRIM(pays));

-- Q7, Q8, Q9 : Sélection
SELECT * FROM bibliotheque.livres WHERE titre LIKE 'L%';

SELECT l.titre, a.nom 
FROM bibliotheque.livres l
JOIN bibliotheque.auteurs a ON l.id_auteur = a.id_auteur;

SELECT titre, (prix_ht * stock) AS valeur_inventaire FROM bibliotheque.livres;

-- Q10 : Agrégation
SELECT id_auteur, AVG(prix_ht) 
FROM bibliotheque.livres 
GROUP BY id_auteur;

-- Q11 : Mise à jour calculée
UPDATE bibliotheque.livres 
SET prix_ht = prix_ht * 1.15 
WHERE id_auteur = 1;

-- Q12 : Suppression conditionnelle
DELETE FROM bibliotheque.livres WHERE stock = 0;
